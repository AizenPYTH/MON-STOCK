## 3. Ce qu'il faut changer (constats)

### 3.1 Sécurité et conformité

| Constat | Gravité | Action |
| --- | --- | --- |
| **Aucune suppression de compte dans l'app** | **Bloquant pour l'App Store public** : Apple impose la suppression dans l'app si l'app permet de créer un compte (règle 5.1.1 v). Pas bloquant pour TestFlight. | Ajouter Réglages → « Supprimer mon compte » (confirmation, suppression côté serveur, sort des organisations dont on est seul propriétaire) |
| Protection des mots de passe divulgués désactivée (Supabase Auth) | moyenne | À activer vous-même : Supabase → Auth → Password security ([doc](https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection)) |
| 12 fonctions `SECURITY DEFINER` appelables par les utilisateurs connectés | faible | Audit du 10 octobre : toutes vérifient l'appartenance à l'organisation ; c'est voulu. À revoir à chaque nouvelle fonction. |
| Extensions `pg_trgm` et `unaccent` dans le schéma `public` | faible | Déplacement possible, mais il touche les index de recherche. À faire hors bêta. |
| 3 tables de secrets avec RLS sans politique | info | Voulu : accès serveur uniquement |
| Un seul projet Supabase (TEST) | élevée avant toute vraie utilisation | Créer un projet de production séparé, avec sauvegardes (PITR) |

### 3.2 Fonctionnel : manques les plus coûteux pour un revendeur eBay

1. **« Marquer expédiée » et n° de suivi depuis la commande.** C'est le flux quotidien principal, aujourd'hui absent. Le handoff le décrit (écran 13).
2. **Scan de code-barres** (EAN / Code 128) pour la recherche stock, l'ajout de colis et la création de produit. Il faut `expo-camera`, donc un build natif.
3. **Ajustement optimiste annulable 5 s** au lieu d'un aller-retour serveur bloquant (handoff, Stepper64).
4. **Publication eBay réelle** : à déverrouiller seulement après un essai sur le bac à sable eBay.
5. **Catalogue limité à 5 000 SKU** (signalé à l'écran). Une pagination serveur sera nécessaire au-delà.

### 3.3 Design : suite du handoff (non faite à ce jour)

- Écrans détaillés : Stepper64 et ChoiceTile (ajustement), AmountField et ResultCard (outils), barre empilée de l'annuaire, recherche fournisseur progressive avec barre par source, import suspendu en feuille.
- **Thème sombre** : les jetons sont fournis, pas encore branchés. Il demande de passer les couleurs par un contexte de thème, soit un passage sur tous les écrans.
- Lignes balayables (−/+), barre de commande universelle, widgets et Live Activity (extension iOS native).
- Brancher `TrustBadge` et `Estimate` sur les champs déjà fournis par l'API (`priceOrigin`, `lastSeenAt`, `missing[]`) dans le Radar, la comparaison et la fiche SKU.

### 3.4 Qualité technique

- **Pas de suivi des plantages en production.** Brancher la télémétrie Expo, ou Sentry, avant d'élargir la bêta.
- **Aucun test de bout en bout sur appareil.** Ajouter Maestro ou Detox sur 5 parcours : connexion, ajustement, synchro eBay, outil TVA, conseiller.
- **Déploiement de l'Edge Function manuel.** Un workflow CI (bundle, tests, puis déploiement TEST sur validation) éviterait les écarts entre code et serveur, comme aujourd'hui.
- **File d'écritures hors ligne demandée par le handoff.** Elle contredit l'écart assumé (docs/MOBILE.md §4.4 : un mouvement rejoué plus tard peut être faux). C'est une décision produit à prendre.
